# WinDiag

Консольная диагностика Windows на C. Без окон приложения, фоновых служб, телеметрии и автоматических изменений системы.

## Возможности

- `diagnose`: снимок загрузки CPU, доступной RAM и commit, свободного места на системном диске и восьми процессов с наибольшим private memory.
- Проверка доступности счётчика PDH `\Memory\Available MBytes`.
- Проверка репозитория WMI командой `winmgmt /verifyrepository`.
- Проверка конфигурации прокси текущего пользователя и WinHTTP. Адрес прокси в журнал не записывается.
- Сводка предупреждений и ошибок из журналов `System` и `Application` за последний час.
- `watch`: снимки раз в минуту и сводка событий раз в час. Журналы разбиваются по часам.
- `mark`: добавить в журнал отметку о начале зависания или другой проблемы.
- Команды `settings`: открыть штатные страницы Windows для уведомлений или Windows Update.

WinDiag не сбрасывает WMI, не перестраивает счётчики, не меняет реестр и не отключает Windows Update. Если проверка счётчиков не проходит, программа только подскажет ручной следующий шаг — проверить `lodctr /R` в командной строке администратора. Сначала нужно убедиться, что проблема действительно в счётчиках.

## Запуск

Скачайте `WinDiag.exe` из [последнего релиза](https://github.com/KiTaUc/WinDiag/releases/latest), откройте CMD или PowerShell в папке с файлом и выполните:

```text
WinDiag.exe diagnose
WinDiag.exe watch 120
WinDiag.exe mark "начались подвисания"
WinDiag.exe settings notifications
WinDiag.exe settings updates
```

`watch 120` ведёт наблюдение два часа; без числа минут работа продолжается, пока не нажать Ctrl+C. Без параметров запускается простое текстовое меню.

Файлы находятся в `%LOCALAPPDATA%\WinDiag\logs` и называются `winddiag_ГГГГММДД_ЧЧ.log`. В журнал попадают локальные показатели системы, имена верхних процессов и ID событий Windows. Перед отправкой кому-либо проверьте журнал на личные данные.

## Сборка из исходников

Исходник `src/windiag.c` написан на C и использует Win32 API. Сборка Windows x64 через MinGW-w64:

```text
x86_64-w64-mingw32-gcc -std=c11 -O2 -Wall -Wextra -Wpedantic -D_WIN32_WINNT=0x0601 src/windiag.c -o WinDiag.exe -static -static-libgcc -lpsapi -lpdh -lwinhttp -lshell32 -ladvapi32
```

Для Windows также настроен GitHub Actions workflow, который собирает x64-версию MSVC и сохраняет её как build artifact.

## Ограничения первой версии

Счётчик проверяется по англоязычному PDH-пути, поэтому результат на нелатинской локализации Windows нужно подтвердить на реальном компьютере. WMI-команда выводит текст штатной утилиты Windows. Диагностика не определяет автоматически первопричину каждого события и не выполняет исправления.
